# DeepSeek‑API‑peak‑monitor
40KB 单文件exe工具，本地计算DeepSeek‑API高峰 / 低峰时段，展示当前状态、切换倒计时、价格参考。无网络请求，不上传用户密钥，适合Harness任务规划调用成本，计价仅供参考。

## 功能
- 实时显示当前处于高峰期 / 低峰期
- 距离时段切换倒计时
- 高峰、低峰档位Token单价参考
- **纯本地时间运算，无网络请求，不会上传任何用户信息，不含API‑Key收集逻辑**

## 使用方法
可执行程序在 [Releases](../../releases) 页面下载，下载exe直接双击运行即可。
